Conexión con Claude (IA)

La foto del ticket se envía a la API de Claude para leer los artículos y precios. Necesitas una API key de console.anthropic.com. Se comparte entre tus dispositivos sincronizados.

Sincronización entre móviles

Con esto configurado en los dos móviles, los grupos, tickets y la API key que suba uno le aparecen al otro. Los datos se guardan en un repositorio privado de GitHub. Necesitas un token de GitHub con permiso de lectura/escritura sobre ese repositorio (mismo token en ambos móviles).
